# AmineKOUAIDI-tp-web

# Évasion du Labo 7

# Présentation

Évasion du Labo 7 est un jeu d'aventure que j'ai fait en HTML et CSS. 
Le joueur est enfermé dans un laboratoire secret et 
il doit réussir à s'échapper en choisissant ce qu'il fait.

# Comment lancer le site

1. Télécharger le projet depuis GitHub.
2. Ouvrir le dossier dans un terminal.
3. Taper dans le terminal de Visual Studio Code : start index.html
Puis le site s'ouvre dans le navigateur.

# Contenu

Le jeu a 11 pages : une page d'accueil et 10 scènes.
Il y a 3 fins différentes : capturé, évadé ou clone.
Chaque scène a un fond animé et une musique.

# Fichiers

index.html : la page d'accueil
pages : les 10 scènes
style.css : le style du site
assets : les images, les icônes et les sons
arbre-navigation.pdf : le schéma du jeu

# Outils

HTML, CSS, Font Awesome, Google Fonts, Visual Studio Code et GitHub.
